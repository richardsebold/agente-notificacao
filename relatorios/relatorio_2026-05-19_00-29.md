O navegador Playwright requer aprovação de permissão na sessão interativa. Há duas opções:

**Opção 1 — Rodar o script Python diretamente** (recomendado — já usa `--dangerously-skip-permissions`):
```
python gerar-relatorio.py
```

**Opção 2 — Liberar o Playwright permanentemente** para esta sessão via `/update-config` e aprovar manualmente cada chamada agora.

O script `gerar-relatorio.py` foi feito exatamente para contornar isso — ele invoca o Claude CLI com `--dangerously-skip-permissions` como subprocess. Execute `python gerar-relatorio.py` no terminal com o `input.txt` já preenchido.
